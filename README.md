# Consulta de Preços (offline)

App web instalável (PWA) para consultar preços e somar vendas sem internet.
Os preços NÃO ficam neste repositório: cada celular importa o arquivo `produtos.json`
gerado no computador a partir do backup do Shop 9.

Ao alterar qualquer arquivo do app, aumente `VERSAO` em `sw.js` para os celulares baixarem a nova versão.
